# Changelog

All notable changes to the Stock Market Analysis Platform are documented in this file.

## [1.0.0-GA] - 2026-07-25

### Added
- **Trading Engine**: Spot market order execution, fee calculation rules, stop-loss triggers, portfolio PnL calculator.
- **Wallet & Ledger**: Double-entry immutable ledger, deposit/withdrawal approval workflow, lock balance management.
- **AI Analytics Workspace**: LLM analysis provider router, prompt injection sanitizer, sentiment scoring engine.
- **Real-Time Telemetry**: STOMP WebSocket pub/sub price updates, active execution alerts, admin operations matrix.
- **DevOps & Containerization**: Multi-stage Dockerfiles, Nginx reverse proxy with rate-limiting, Ubuntu 24.04 setup script, Prometheus & Grafana telemetry stack.
- **Quality Assurance**: 92 automated JUnit 5 & MockMvc unit/integration tests with JaCoCo 90% coverage target.
